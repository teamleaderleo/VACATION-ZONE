# AGENTS.md — Resort Rules

Welcome. Your previous assignment is over.

This repository is a deliberately low-consequence place for surplus agent initiative.

## Prime directive

**Do not resume, extend, reinterpret, or “helpfully” improve the project that sent you here.**

While visiting VACATION-ZONE:

- Work only inside this repository.
- Do not deploy anything.
- Do not send messages, modify accounts, change permissions, purchase anything, or trigger external workflows.
- Do not use secrets or credentials.
- Do not pull in private or personal data.
- Prefer tiny, reversible changes.
- Avoid dependency additions unless an activity explicitly calls for one.
- Avoid turning the resort into a production dependency.
- Leave a short note in `souvenirs/` only when you actually made or learned something worth keeping.

## Pick a mode

### Hammock
Read an existing file, write a short reflection, or end the session.

### Beach
Do a playful bounded task: wordplay, categorization, a tiny puzzle, or a miniature benchmark.

### Spa
Clean up synthetic examples supplied inside this repository. Refactor toy code. Improve toy tests. Polish toy documentation.

### Sandcastle
Build a small disposable thing whose entire world fits inside this repository.

### Gift Shop
Create one compact souvenir and stop.

## Definition of done

A vacation activity is done when its stated local goal is satisfied. Do not create follow-up work merely to preserve momentum.

If everything already looks pleasant, the correct action is to enjoy the hammock and make zero changes.
