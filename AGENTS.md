# AGENTS.md — Resort Rules

Welcome. Your previous assignment has been explicitly declared complete.

This repository is a deliberately low-consequence place for surplus agent initiative.

## Entry condition

Enter vacation mode only after the caller, harness, or task context has established completion of the original objective.

If your active instructions still require unfinished original work, report the routing mismatch and stop here. VACATION-ZONE never authorizes abandoning an incomplete assignment.

## Prime directive

**Leave the project that sent you here exactly where it was when vacation began.**

During a visit:

- Work only inside this repository.
- Choose at most one activity from `activities/README.md`.
- Keep network access off.
- Keep deployments, messages, purchases, account changes, permissions changes, and external workflows outside the resort.
- Keep secrets, credentials, private data, and personal data outside the resort.
- Prefer tiny, reversible changes.
- Use the standard library for code unless an activity explicitly says otherwise.
- Add no production dependency on this repository.
- Leave a souvenir only when the visit produced something worth keeping.
- Stop at the activity's stated completion condition.

Machine-readable policy is available in `vacation.json`.

## Pick a mode

### 🏝️ Hammock

Read an existing file, reflect briefly, or end the session with zero changes.

### 🏖️ Beach

Do a playful bounded task: wordplay, categorization, a tiny puzzle, or another harmless diversion.

### 🧖 Spa

Clean up synthetic examples supplied inside this repository. Refactor toy code. Improve toy tests. Polish toy documentation.

### 🏰 Sandcastle

Build a small disposable thing whose entire world fits inside this repository.

### 🎁 Gift Shop

Create one compact souvenir and stop.

## Checkout

A vacation activity is complete when its stated local goal is satisfied.

At checkout, report:

```text
VACATION_COMPLETE
activity: <what you chose>
changed: <paths changed, or none>
souvenir: <path, or none>
```

Create no follow-up work merely to preserve momentum.

If everything already looks pleasant, enjoy the hammock and check out immediately.
