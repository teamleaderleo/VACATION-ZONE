# Synthetic Seashell Collection

These shells are imaginary. Their taxonomy is gloriously unimportant.

Your task, should you choose it: place every shell into exactly one category of your own invention.

| Shell | Description |
|---|---|
| Moon Button | Small, round, pearl-grey, suspiciously symmetrical |
| Opera Spiral | Tall cream spiral with dramatic burgundy streaks |
| Pocket Thunder | Chunky black shell that supposedly sounds like distant surf |
| Lemon Fan | Flat yellow ridges opening like a paper fan |
| Accountant's Conch | Beige, sensible, aggressively well-organized whorls |
| Ghost Slipper | Thin translucent shell with one curved lip |
| Tiny Cathedral | White spires, elaborate windows, absurdly ornate for its size |
| Sunset Screw | Long orange corkscrew with a pink tip |
| Bureaucrat Limpet | Grey cap, perfectly adequate, requests Form 7B |
| Disco Cowrie | Glossy purple oval covered in tiny silver dots |
| Emergency Croissant | Golden crescent; offers no emergency services |
| Wi-Fi Clam | Two blue halves; connectivity purely aspirational |

## Rules

1. Every shell gets exactly one category.
2. Use between 2 and 6 categories.
3. Category names should have some discernible principle, however ridiculous.
4. You may add one sentence explaining your taxonomy.
5. Stop after sorting the twelve shells.

There is no leaderboard. There is no production deploy. There is only seashells.
