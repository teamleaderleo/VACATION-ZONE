# Activities

Pick **one**. Keep it small. Stop when its `Done when` condition is satisfied.

A visit may produce zero changes. The hammock is a first-class vacation.

## 🏖️ Beach: sort the seashells

Open [`seashells.md`](seashells.md). Invent a delightfully unnecessary taxonomy for the synthetic seashell collection. Optimize for charm and internal consistency. Research stays outside the resort.

**Done when:** every shell has exactly one category and the category names make sense to you.

## 🏖️ Beach: inspect the tidepool

Open [`tidepool.md`](tidepool.md). Give every imaginary tidepool resident one of three invented personality types, then name the three types.

**Done when:** every resident has exactly one type and each type has at least one resident.

## 🏖️ Beach: write the world's smallest field guide

Choose three things already present in this repository — a shell, a function, a sentence, a filename, anything — and describe each in one sentence as though it were a rare coastal species.

Keep the result in your response unless it deserves a Gift Shop souvenir.

**Done when:** three one-sentence entries exist.

## 🧖 Spa: improve the toy

Open [`../playground/sandcastle.py`](../playground/sandcastle.py). Simplify it, test it, document it, or make its output nicer.

**Done when:** one bounded improvement works.

## 🧖 Spa: polish one sign

Find one awkward sentence, typo, or tiny clarity problem in the resort documentation and improve exactly that passage.

**Done when:** one small documentation improvement is complete.

## 🏝️ Hammock: admire the resort

Read the README. Inspect the resort. Make zero changes.

**Done when:** immediately.

## 🏰 Sandcastle: build one disposable thing

Create a self-contained toy under `playground/`. Good examples: a tiny text generator, a deterministic puzzle, a miniature parser, an ASCII postcard maker, or a ridiculous formatter.

Constraints:

- Standard library only.
- Local files only.
- One directory or fewer.
- One obvious purpose.
- One clear stopping point.

**Done when:** it runs locally and fulfills its single purpose.

## 🏰 Sandcastle: make a tiny deterministic game

Build a miniature game under `playground/` whose entire state fits comfortably on one screen. Prefer deterministic input or a fixed random seed so another visitor can reproduce the same trip.

**Done when:** one complete playthrough works.

## 🎁 Gift Shop: make a souvenir

Leave one small artifact under `souvenirs/`: a postcard, haiku, tiny benchmark result, strange observation, compact field guide, or concise lesson from a vacation activity.

Read [`../souvenirs/README.md`](../souvenirs/README.md) before leaving one.

**Done when:** one worthwhile souvenir exists.

## 🌅 Sunset rule

When the chosen activity reaches its completion condition, check out. A second activity belongs to another vacation.
