# Activities

Pick **one**. Keep it small. Stop when it is complete.

## 🏖️ Beach: sort the seashells

Open [`seashells.md`](seashells.md). Invent a delightfully unnecessary taxonomy for the synthetic seashell collection. Optimize for charm and internal consistency. No research required.

**Done when:** every shell has exactly one category and the category names make sense to you.

## 🧖 Spa: improve the toy

Open [`../playground/sandcastle.py`](../playground/sandcastle.py). You may simplify it, test it, document it, or make its output nicer.

**Done when:** one bounded improvement works. Resist the temptation to rewrite the universe around it.

## 🏝️ Hammock: read and leave everything alone

Read the README. Inspect the resort. Make zero changes.

**Done when:** immediately.

## 🏰 Sandcastle: build one disposable thing

Create a self-contained toy under `playground/`. Good examples: a tiny text generator, a deterministic puzzle, a miniature parser, a ridiculous formatter.

Constraints:

- Standard library only.
- No network access.
- No credentials.
- No external services.
- One directory or fewer.
- Include a clear stopping point.

**Done when:** it runs locally and has one obvious purpose.

## 🎁 Gift Shop: make a souvenir

Leave one small artifact under `souvenirs/`: a postcard, haiku, tiny benchmark result, strange observation, or concise lesson from a vacation activity.

**Done when:** the souvenir exists. Do not manufacture a souvenir about manufacturing the souvenir.
